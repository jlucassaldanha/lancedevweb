# 3. Uso do Stitch para Prototipação Rápida

**Data:** Outubro de 2026

### Contexto
Para evitar o "desenvolvimento às cegas", que frequentemente resulta em retrabalho de CSS e quebra de layout, era necessário ter uma visão clara da disposição das telas de Vitrine, Laudo e Comprovante antes de codificá-las.

### Decisão
Utilização da ferramenta **Stitch** para criar rascunhos (*sketches*) e planejar a hierarquia visual dos componentes iniciais antes da implementação com Tailwind.

### Consequências

*   **Positivas:** Trouxe clareza sobre o que seria necessário transformar em componente reutilizável (ex: Cards de Lote, Botões de Status). Agilizou o mapeamento de quais dados a API deveria fornecer em cada tela.
*   **Negativas:** Demandou um tempo extra de planejamento inicial na prancheta de desenho, reduzindo as horas puras de codificação.
